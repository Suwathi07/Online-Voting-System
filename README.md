# Online-Voting-System
A simple and user-friendly Online Voting System built with Java Swing. It allows voters to register and cast their votes, while admins can manage candidates and view election results securely and efficiently.
# Features
🔐Admin Login
👤 Voter Registration
🧑‍💼 Add Candidates
🗳️ Cast Vote
🚫 Prevent Multiple Voting
📊 View Election Results
🏛️ Multiple Election Types
# Technologies Used
Java
Java Swing
Java Collections
# Project Files
Candidate.java
Election.java
Voter.java
VotingSystemGUI.java
# How to Run
Open the project in a Java IDE and run:
VotingSystemGUI.java
